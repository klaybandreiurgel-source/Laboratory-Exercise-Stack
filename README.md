# Java Laboratory Activities

## Description

This repository contains our Java laboratory activities focusing on data structures, recursion, and basic programming concepts. These activities helped us understand how different algorithms work through actual implementation and program execution.

## Laboratory Activities

### 1. Stack – Delimiter Checker

This program uses a stack to check whether opening and closing delimiters are properly matched.

**Stack Operations:**
- Push
- Pop
- Peek
- isEmpty

The program demonstrates the Last-In, First-Out (LIFO) principle.

### 2. Recursive Search Trace

This program demonstrates how recursion can be used to search for a target value inside an array.

It displays each step of the recursive search, including the index and value being checked.

## Programming Language

Java

## Development Environment

Apache NetBeans IDE

## Purpose

The purpose of these laboratory activities is to improve our understanding of Java programming, stack operations, and recursive algorithms through hands-on exercises.
